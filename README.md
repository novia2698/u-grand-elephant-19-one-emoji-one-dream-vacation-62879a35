One emoji, one dream vacation: a desert island (🏝️). The program writes that single emoji — nothing else, no words, no newline — to `entry.txt`, and the judge picks the emoji that most makes a stranger want to book the flight. A desert island is the postcard everyone already carries in their head: turquoise water, white sand, one palm, nowhere to be.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
cat out/entry.txt
```
